# Как составлять ENVIRONMENT.md

> Реконструкция по описанию на Confluence («Шаблон ИИ-мета-репо», space ADT, pageId 195789365). Оригинал шаблона: `https://gitlab.com/rcktsci/projects/ai/meta-repo-template` — на текущих токенах недоступен; сверить с оригиналом при получении доступа.

`ENVIRONMENT.md` — машинно-специфичное описание окружения. Файл подключён через `instructions` в `.opencode/opencode.jsonc` и автоматически попадает в системный промпт каждой сессии. Шаблон для заполнения: [ENVIRONMENT-example.md](ENVIRONMENT-example.md).

Правила:

1. В Git не входит (исключён через `.gitignore`). Создаётся на каждой машине вручную по этому файлу и примеру.
2. Описывать только то, что влияет на работу ИИ: ОС и оболочка, пути к репозиториям, версии инструментов, локальные сервисы, известные особенности и ограничения машины.
3. Секреты, токены и пароли не указывать — только ссылки на корневой `.env`.
4. Абсолютные пути уместны только здесь: файл не переносится, в отличие от остального репозитория.
5. Обновлять при изменении окружения; устаревший факт опаснее отсутствующего.
