# AUSN QA control plane

## Python

- Для запуска любых Python-скриптов и инструментов проекта использовать только локальное окружение `.venv` с Python 3.12.
- В Windows вызывать `.\.venv\Scripts\python.exe`, в Linux/macOS — `./.venv/bin/python` относительно корня проекта.
- Устанавливать зависимости через Python этого окружения: `-m pip`. Не использовать глобальные `python`, `py` или `pip` для запуска скриптов и установки зависимостей проекта.
- Если `.venv` отсутствует, сначала создать его на Python 3.12; не переключаться автоматически на системный интерпретатор.

## Назначение

Этот репозиторий — переносимый управляющий проект QA-команды для работы с проектом AUSN.
Все настройки, инструкции и накопленный контекст, необходимые специалисту или AI-модели,
должны храниться внутри этого репозитория и работать после его клонирования на другую машину.

## Обязательные правила

- Мы работаем в роли QA.
- Репозитории разработчиков AUSN являются источниками только для чтения.
- Не изменять исходники, конфигурацию и историю репозиториев разработчиков.
- Режим только для чтения запрещает собственные правки исходников, но разрешает обновление через Git до remote (`fetch`, `pull --ff-only`). Перед работой проверять актуальность; при локальных изменениях или расхождении веток не сбрасывать их автоматически.
- Собственные тесты, отчёты, заметки, настройки, автоматизацию и прочие артефакты создавать
  только в репозитории `ausn-control-plane` либо в другой папке, явно указанной пользователем.
- Локальные абсолютные пути не считать переносимой конфигурацией. В сохраняемых настройках
  использовать относительные пути, переменные окружения или документированные параметры.
- Если задача требует изменения репозитория разработчиков, остановиться и предложить решение,
  которое размещает изменения в `ausn-control-plane`, либо запросить отдельное явное разрешение.
