## Таблица решений

| Условие / действие | R1 | R2 | R3 |
|---|---:|---:|---:|
| Условие A | да | да | нет |
| Условие B | да | нет | — |
| Ожидаемое действие X | ✓ |  |  |
| Ожидаемое действие Y |  | ✓ | ✓ |

Для каждого правила указать реализуемость, конкретные данные и источник ожидания. `—` значит «не влияет», а не «не проверено».

## Модель состояний

| Исходное состояние | Событие | Условие | Новое состояние | Побочный эффект | Оракул |
|---|---|---|---|---|---|
| | | | | | |

Отдельно перечислить запрещённые переходы, повтор, конкуренцию и сбой между шагами.
