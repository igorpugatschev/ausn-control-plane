# Презентации

## `ausn-control-plane-qa-layer.pptx` — управляющий слой QA и его продукт

19 слайдов. Регламент выступления — 30–45 минут + вопросы; аудитория смешанная (разработчики, аналитики,
QA, управленцы), поэтому слайды — простыми словами, а технические подробности (ключи, пути, команды,
цифры) вынесены в **заметки к слайдам**.

### Структура

| № | Слайд | Вид |
|---|---|---|
| 1 | Титул | тёмный |
| 2 | Маршрут (4 вопроса) | карточки |
| 3 | Что мы тестируем | карточки |
| 4 | Термины простыми словами (глоссарий) | карточки |
| 5 | Как всё связано: три контура | **диаграмма** (источники → управление → продукт, стенд) |
| 6 | Что внутри управляющего слоя | карточки |
| 7 | Как агент получает доступ (MCP) | **диаграмма** (клиент → прокси → шина серверов) |
| 8 | Зачем каждая группа доступа | карточки с примерами |
| 9 | Контекст кода | **диаграмма** потока + стат-выноски |

| 11 | Роли ИИ: конвейер с ревью | **диаграмма** (pipeline + возврат на доработку) |

| 13 | Дисциплина разбора падений | **диаграмма активности** (activity, дерево решений) |

Все диаграммы — **нативные фигуры и диаграммы PowerPoint** (не картинки): их можно править в редакторе.

Стиль: светлый фон `F0F2F6`, насыщенный синий `0060F0`, тёмный `001030`, дополнительно зелёный (успех)
и янтарный (среда/ограничения). Формат 16:9.

### Как пересобрать

Источник — `build.js` (pptxgenjs). Правки вносятся в скрипт, а не в бинарник.

```bash
npm install pptxgenjs              # один раз
node build.js                      # соберёт ausn-control-plane.pptx рядом со скриптом
copy ausn-control-plane.pptx ausn-control-plane-qa-layer.pptx
```

Проверка перед публикацией:

```bash
python <skills>/anthropic-pptx/scripts/office/validate.py ausn-control-plane-qa-layer.pptx
```

На Windows валидатор требует UTF-8-режима Python: `set PYTHONUTF8=1`.
