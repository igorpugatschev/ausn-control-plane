# Презентации

## `ausn-control-plane-qa-layer.pptx` — управляющий слой QA и его продукт

16 слайдов: контекст, управляющий слой, взаимодействие с системой через MCP, цикл создания продукта,
фреймворк автотестов по слоям, результаты (покрытие, стабильность наборов, регресс-планы), находки, итоги.

Стиль: светлый фон `F0F2F6`, насыщенный синий `0060F0`, тёмный `001030` (образец —
презентация по ИИ в АУСН; формат 16:9).

### Как пересобрать

Источник — `build.js` (pptxgenjs). Правки вносятся в скрипт, а не в бинарник.

```bash
npm install pptxgenjs          # один раз, в этой папке или выше
node build.js                  # соберёт ausn-control-plane.pptx рядом со скриптом
```

Затем обновить бинарник:

```bash
copy ausn-control-plane.pptx ausn-control-plane-qa-layer.pptx   # Windows
```
