# Баг-репорт: кнопка отметки прочтения уведомления недоступна в UI

**Статус:** готов к публикации пользователем (агент сам не публикует).
**Дата:** 2026-09-23. **Стенд:** `ausn-test1` (192.168.100.105:8001, профиль Агророс/`isimple`).
**Источник:** QA ledger `ausn-qa-project/docs/reports/qa-loop-ui-account-sections-2026-09-22.md`, `QL-124`.

## Заголовок

`[UI][Оповещения] Кнопка «Отметить прочитанным» невидима и перекрыта датой — отметить уведомление прочитанным через UI нельзя`

## Окружение

- test1, UI кабинета АУСН в iframe-харнессе банка (Агророс), роль `AUSN_FULL`, ИНН `731943412869`.
- Уведомление создано штатным путём: сообщение `NOTIFICATIONS` в Kafka-топик `ausn.notifications`
  (front-module создаёт его со статусом `UNACKNOWLEDGED`).

## Шаги воспроизведения

1. Отправить в `ausn.notifications` сообщение `{"type":"NOTIFICATIONS","body":{"innNotificationsList":[{"inn":"731943412869","hasMore":false,"notificationInfoList":[{"messageId":<уникальный>,"header":"...","message":"...","notificationType":"PARTNER_GRANT_APPROVE","notificationStatus":"UNACKNOWLEDGED","creationDateTime":"<ISO>"}]}]}}`.
2. Дождаться появления уведомления (`GET /api/v1/notification` — статус `UNACKNOWLEDGED`).
3. Открыть раздел «Оповещения» (`/notification/messages`).
4. В карточке непрочитанного уведомления (метка «Новое») найти кнопку «Отметить прочитанным».

## Фактический результат

- Кнопка присутствует в DOM (`button[class*='markAsReadButton']`), но:
  - `is_visible()` = **false** (Playwright считает элемент невидимым);
  - `document.elementFromPoint(центр кнопки)` возвращает `time._headerDatetime` — **кнопка перекрыта меткой времени**;
  - обычный клик недоступен (элемент не проходит проверку доступности), клик с `force` попадает в дату и не срабатывает.
- Обработчик при этом рабочий: программный `element.click()` вызывает
  `PUT /api/v1/notification/{id}/status/ACKNOWLEDGED` → 200, статус становится `ACKNOWLEDGED`,
  в `ausn.notifications-status-in` уходит `NOTIFICATIONS_STATUS_UPDATE` (проверено, `QL-123`).
- Дополнительно: открытие карточки уведомления не помечает его прочитанным
  (UC-5 предполагает автоматическую отметку при открытии).

## Ожидаемый результат

- Кнопка «Отметить прочитанным» видима и кликабельна; после клика уведомление получает статус
  «Прочитано», счётчик непрочитанных уменьшается, в `ausn.notifications-status-in` уходит
  `NOTIFICATIONS_STATUS_UPDATE` с `id` = externalId уведомления.
- Уточнить у аналитика: должна ли отметка происходить автоматически при открытии уведомления (UC-5).

## Классификация

- `product_bug` (UI, вёрстка/доступность элемента), приоритет: средний (функция отметки недоступна из UI,
  но контракт API и Kafka-уведомление работают).
- Воспроизводимость: стабильно (проверено на живой сборке; тест-кейс `QL-124` оформлен как `xfail(strict=True)` —
  при исправлении станет `XPASS` и потребует снятия маркера).

## Доказательства

- DOM-фрагмент карточки (класс `_markAsReadButton_moxuc_90`, обработчик `markAsRead` присутствует в сборке).
- `is_visible()` = false; `elementFromPoint` → `time._headerDatetime`.
- Запрос `PUT /api/v1/notification/{id}/status/ACKNOWLEDGED` → 200 (после программного клика).
- Секреты, токены и персональные данные в отчёт не включаются.
