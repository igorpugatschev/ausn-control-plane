# Область тестирования «Коробки» ПК АУСН

## Основной объект QA

Агророс — основная переносимая реализация ПК АУСН, то есть «Коробка». Проверки функциональности, интеграций и базовая регрессия выполняются на стенде Агророс через единственную UI-точку:

`http://192.168.100.105:8001/iframe-test.html`

Авторизация на тестовой странице выполняется по ИНН.

## Банковские адаптации

Остальные банковские варианты являются адаптациями «Коробки» под условия конкретных банков. Они не входят в базовый регрессионный контур Агророса.

Банковскую адаптацию проверять отдельно, только когда задача затрагивает её специфические условия, например:

- банковский профиль или feature flags;
- способ авторизации и передачи контекста клиента;
- front-gateway или контракт ДБО;
- отображение/встраивание UI;
- банковские маппинги и ограничения.

Общие изменения сначала проверять на Агроросе. Расширять проверки на конкретные банки нужно по impact-анализу изменения, а не автоматически на весь перечень адаптаций.
