## Уровни уверенности

- **Подтверждено**: прямой ответ API/MCP или read-only команда с указанной датой.
- **Поддержано**: согласуется минимум с двумя независимыми источниками.
- **Гипотеза**: обсуждение, проектный документ или вывод, требующий runtime-проверки.

Во всех последующих отчётах указывать один из этих уровней для существенных выводов.
