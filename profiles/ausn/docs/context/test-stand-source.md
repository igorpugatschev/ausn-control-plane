# Основной тестовый стенд ПК АУСН

Авторитетный источник конфигурации: Confluence page `195790883`.

Страница содержит актуальную карту сервисов основного test1, банковские frontend/gateway endpoints, параметры Keycloak и тестовые учётные данные. Из-за наличия секретов и тестовых идентификаторов её содержимое не копируется в Git и локальные plaintext-файлы.

## Регулярное использование

1. Получить страницу `195790883` через Atlassian MCP непосредственно перед тестовой сессией.
2. Использовать актуальную версию страницы как runtime secret только в памяти текущей сессии.
3. Не выводить пароли, токены, cookie и тестовые идентификаторы в ответы, логи и evidence pack.
4. Для основного стенда считать эту страницу авторитетнее legacy URL из локального `.env`.
5. При изменении версии страницы заново проверить требуемые endpoint через Playwright/SSH MCP.
