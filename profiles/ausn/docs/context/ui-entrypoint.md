# UI-точка тестирования основного стенда

Единственная точка входа для UI-тестирования:

`http://192.168.100.105:8001/iframe-test.html`

Страница: «Тест Агророс».

Авторизация выполняется по ИНН: поле «ИНН» и кнопка «Применить». Разрешённые тестовые ИНН получать непосредственно перед сессией из Confluence page `195790883` через Atlassian MCP. Не сохранять ИНН в Git, отчётах и логах.

Другие банковские frontend URL не использовать как UI-точки тестирования без отдельного указания пользователя.

Проверено через Playwright MCP: 2026-09-08, страница открывается и форма доступна.
