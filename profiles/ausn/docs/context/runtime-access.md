локальные SSH-ключи для стендов не требуются):

| Сервер MCP | Хост | Назначение |
|---|---|---|
| `vm/ausn-test1` | `root@192.168.100.105` | контейнеры приложения test1 |
| `vm/ausn-infra` | `root@192.168.100.104` | postgres, keycloak, kafka, redpanda |
| `vm/ausn-test2` | `root@192.168.100.109` | контейнеры test2 |

Команды только для чтения (проверено 2026-09-18 на `vm/ausn-test1`, 15 контейнеров в состоянии `Up`):

```bash
docker ps --format '{{.Names}}|{{.Status}}'      # состояние контейнеров
docker logs --tail 100 <container>              # логи внутри контейнера
docker inspect <container> --format '{{.Config.Image}}'   # образ
```

Учётные данные старого контура (`192.168.20.18`) непригодны: хост выведен из эксплуатации,
аутентификация на текущих стендах отклоняется. Хранить их в `.env` не следует.
