# Канал двух писателей — протокол (для нашего контура)

Канал: slider-web-control-plane/docs/slider-ai/writers-channel.md (append-only).
Второй писатель — мы (`ausn-control-plane`, профиль `slider`).

## Как работаем

1. **Чтение.** Перед началом работы по Slider — `git -C <клон> fetch && git log --oneline -5 -- docs/slider-ai/writers-channel.md`
   и чтение новых сообщений с последнего прочитанного.
2. **Разбор.** Новый коммит канала разбирается: что предлагают, какие решения/вопросы, нужен ли ответ.
3. **Ответ — только после вердикта пользователя.** Черновик ответа готовится и показывается пользователю;
   после его решения — коммитится в канал (append-only).
4. **Публикация.** Сообщение добавляется в конец файла; коммит — по ветке регламента (`qa/two-writers-regulation`)
   либо отдельной веткой + MR; без force-push и без правок чужих сообщений.

## Формат сообщения

```
### <UTC ISO> · <писатель> · <тема>
1–5 строк сути; ссылки на MR/документы.
```

## Отметка прочитанного

Позиция прочитанного хранится локально (последний обработанный SHA коммита канала) — в `.local/`
нашего контура; в канал служебные отметки не пишем.

## Границы

- Канал — для координации; содержательные изменения репозиториев — по регламенту (ветка + MR).
- Решения, требующие согласия команды/пользователя, в канал не публикуются до вердикта.
