# Упаковка Контекста АУСН

## Цель

Дать агенту ровно тот контекст, который нужен для точного действия: правила, источник контракта, релевантные файлы, полный лог ошибки и критерии готовности.

## Порядок Контекста

1. Правила: `AGENTS.md`, релевантный навык, `ausn-control-plane/profiles/ausn/docs/context/README.md`.
2. Источники: SocratiCode, OpenAPI, Jira/Confluence, GitLab, БД.
3. Файлы: только те, которые читаются или меняются.
4. Ошибка: полный stacktrace или полный вывод команды.
5. Цель: что должно измениться и как проверить.

## Режимы

- Краткий режим: один endpoint, один тест, один файл.
- Расширенный режим: новая UC, Kafka flow, БД, несколько сервисов.
- Сводка: когда данных много, сначала дать карту файлов и фактов, затем читать детали по необходимости.

## MCP

- SocratiCode — поиск по индексированному коду и документации.
- `test_pgdb` — схемы и фактическое состояние БД.
- GitLab — исходники и diff задач.
- Atlassian — Jira/Confluence.
- Graylog/Grafana — логи и состояние сервисов.

## Стоп-Сигналы

Остановиться и уточнить, если:

- два источника говорят разное;
- endpoint, topic или таблица не определены;
- тест использует фикстуру, которой нет в проекте;
- вывод основан на памяти, а не на прочитанном источнике;
- ошибка пересказана, а не приложена полностью.

## Проверка

- Прочитаны правила и релевантные источники.
- Контекст не раздут нерелевантными файлами.
- Все предположения названы явно.
- В отчёте есть список прочитанных источников.
