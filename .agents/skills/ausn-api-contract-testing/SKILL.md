# Контрактное API-Тестирование

## Принцип

Сначала контракт, потом тест. Контракт включает метод, endpoint, параметры, тело запроса, тело ответа, статусы успеха и ошибки.

## Что Проверять

- Успешные статусы строго по спецификации.
- Response body целиком через Pydantic.
- 401 без токена для защищённых endpoint'ов.
- 403 для чужой роли, чужого ИНН или недостаточных прав.
- 400/404/409/422 по негативным сценариям.
- Пагинацию: минимальный лимит, максимальный лимит, отрицательные значения, offset вне диапазона.
- Обратную совместимость: новые поля в ответах делать опциональными в моделях тестов, если контракт допускает постепенный rollout.

## Порядок

1. Найди источник контракта через `ausn-source-driven-development`.
2. Посмотри похожий тест в `tests/api/` или `tests/tooling/`.
3. Проверь фикстуры в `tests/conftest.py`.
4. Добавь или обнови Pydantic-модель.
5. Напиши тесты success, auth, validation и boundary cases.
6. Запусти узкий pytest, затем `ruff check` и релевантный marker.

## Паттерны

- Разделяй модели запроса и ответа.
- Не проверяй только `status_code`.
- Не парси ответ ручными цепочками `response.json()["field"]`, если поле относится к контракту.
- Для ошибок используй единую модель ошибки, если API её поддерживает.
- Русский бизнес-текст размещай в `docstring` и комментариях; в декораторах `@allure.*` и `@pytest.*` — только ASCII: encoding gate продукта запрещает кириллицу в декораторах.

## Проверка

- Контракт записан в комментарии, docstring или allure story.
- Все protected endpoint'ы имеют auth-негатив.
- Pydantic-модель покрывает весь значимый ответ.
- Негативные сценарии не создают состояние, которое ломает параллельный запуск.

## Откуда правила

- Из базы `docs/qa-methodology/`: `system-testing.md#API` и `#Данные и транзакции` (проверять тело и модель, а не только статус), `test-design.md#Классы эквивалентности и границы` (negative и boundary), `automation.md#Качество теста` (параллельный запуск и изоляция).
- Из практики: запрет кириллицы в декораторах `@allure.*`/`@pytest.*` — урок 3 ретроспектив.
